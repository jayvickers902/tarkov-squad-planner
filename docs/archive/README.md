# Archive — historical documents

Everything in this folder is **superseded**. These are briefs, handoffs and plans written during
development; the designs they describe have since changed, shipped differently, or been abandoned
outright.

**Do not treat any of it as current specification.** For how the app works today, read
[CLAUDE.md](../../CLAUDE.md) and the deep references in [docs/](../), then the code.

They are kept for provenance — a few source comments cite one by path to explain why a piece of
code is shaped the way it is (`docs/archive/IMPLEMENTATION-PLAN.md`,
`docs/archive/PHASE7-HANDOFF.md`, `docs/archive/PHASE8-HANDOFF.md`,
`docs/archive/CODEX-HANDOFF-preraid.md`). Those citations are the only reason to open a file here.
